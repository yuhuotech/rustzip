# RustZIP 稳定性测试用例实施清单

日期：2026-10-24。状态：**S0 覆盖基线、S1 首批和 S2 的 GUI-02/LOC-06 异步竞态变体已执行；逐用例结果、平台边界和剩余项见 [执行报告](testing-s1-report.md)**。主方案见 [测试覆盖率与稳定性提升实施方案](testing-stability-plan.md)。

## 使用规则

- 每行是一个用例族，可展开多个格式、feature、平台和故障阶段变体，不等于一个 `#[test]`。
- “扩展”表示已有相关测试，需要补异常、断言或环境；“新增”表示未找到充分对应的确定性验证，不表示已确认产品存在该缺陷。
- 每个变体登记 `未实施 / 已实现未执行 / 通过 / 失败 / 环境未覆盖 / NA`，并链接日志。仅本机人工操作不能自动填为三平台通过。
- 数据安全断言集 A：源哈希、旧目标哈希、输出路径和内容清单、目标外哨兵、临时文件、错误码与终态、超时；不适用项注明。
- 所有测试仅使用隔离夹具、临时卷、测试进程和测试账号；不读取用户真实密码，不依赖开发者个人 Downloads；不要用删除真实目录、填满系统盘或随机杀开发者进程制造故障。
- 下面的目标文件是拟落点，尚未创建的文件允许在实施时小幅合并。集成文件不要调用 GUI 私有实现来伪造功能通过，优先真实事件与可观测结果。
