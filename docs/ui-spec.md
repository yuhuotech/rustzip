# UI 规范

视觉稿见 `docs/ui/preview.html`(可直接用浏览器打开,含浏览、新建压缩、任务三个界面和明暗主题)。**实现时以视觉稿为准**,本文件是其文字化的规范。

## 1. 设计风格

**简洁、大气、克制。** 冷灰中性色为底,只有一个青绿强调色,仅用于主操作和选中状态。数字、路径、大小用等宽字体对齐。留白充足,信息层级靠字重和灰度区分,不靠装饰。

原则:
1. 一个强调色,不滥用。
2. 默认只露出常用选项,高级项折叠。
3. 明暗主题都要认真做,默认跟随系统,可手动切换。
4. 状态用形态表达,而不只靠颜色(图标、文字、进度条)。
5. 界面不得出现卡顿:所有耗时操作在后台,界面始终可操作。

## 2. 色彩令牌

实现时必须用语义令牌,**不得在组件里写死颜色值**。

| 令牌 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `bg` | 应用背景(窗口外) | `#e9edf1` | `#080c10` |
| `win` | 窗口 / 主内容底 | `#ffffff` | `#11171d` |
| `panel` | 侧栏、标题栏、状态栏 | `#f5f7f9` | `#0d1318` |
| `line` | 分割线、边框 | `#e2e7ec` | `#212b34` |
| `fg` | 主文字 | `#121c26` | `#e7eef4` |
| `fg2` | 次要文字 | `#56677a` | `#98a8b6` |
| `fg3` | 弱化文字、占位 | `#8896a4` | `#64737f` |
| `accent` | 强调色 | `#0d9b82` | `#2fd3a7` |
| `accent-ink` | 强调色上的文字 | `#ffffff` | `#04231b` |
| `accent-soft` | 选中行、强调浅底 | `#dff4ee` | `#11342c` |
| `hover` | 悬停底色 | `#eef2f5` | `#18212a` |
| `warn` | 警告 | `#c98200` | `#e5a62a` |
| `danger` | 危险、删除 | `#d23f3f` | `#ef6b6b` |

语义色(警告、危险)与强调色是两回事,不得混用。

## 3. 字体

- 界面字体**跟随系统**:macOS 苹方、Windows 微软雅黑 UI(或 Segoe UI Variable)、Linux 思源黑体(Noto Sans CJK)。视觉稿用 Geist 仅为预览效果。
- 数字、路径、大小、日期:等宽字体(Geist Mono / SF Mono / Consolas),开启等宽数字,保证列对齐。
- 字号:正文 14、次级 13、辅助 12、小标签 11(大写加字距)、面板标题 18、详情标题 15。
- 字重只用 400 / 500 / 600。
- 必须验证中日韩字体回退和输入法组合输入(见 `decisions.md`)。

## 4. 形状与间距

| 项目 | 值 |
|---|---|
| 窗口圆角 | 14 |
| 卡片、预设卡圆角 | 12 |
| 控件(按钮、输入框)圆角 | 8 |
| 药丸 / 标签 | 全圆角 |
| 文件列表行高 | 38(表头 34) |
| 工具栏内边距 | 10 14 |
| 基本间距单位 | 4 的倍数(4 / 8 / 12 / 16 / 24) |
| 边框 | 1px,颜色 `line` |

阴影只用于浮层和窗口,列表和卡片不加阴影。

## 5. 布局

### 主窗口(浏览)

```
┌ 标题栏:窗口控制 + 压缩包标签页 + 新建标签 ─────────────────┐
├ 工具栏:[解压到…(主)] 添加 测试 删除 │ 预览 ········ 搜索 ┤
├ 侧栏 196 ┬ 路径面包屑 ──────────────────┬ 详情 288 ┤
│ 位置      │ 文件表:名称 | 大小 | 压缩后 | 修改时间 │ 预览图    │
│ 快速操作  │ (虚拟化列表,点击选中)          │ 名称 / 类型│
│          │                              │ 属性列表   │
│          │                              │ [解压此项] │
├ 状态栏:校验结果 · 条目数 · 体积变化 · 压缩率 ··· 格式信息 ┤
└────────────────────────────────────────────────┘
```

- 三栏:侧栏 196、详情 288,中间自适应。
- 窗口宽度小于约 980 时隐藏详情栏;小于约 720 时再隐藏侧栏,并隐藏"压缩后"和"修改时间"两列。
- 一个工具栏里只有一个主按钮(强调色填充),即"解压到…"。

### 新建压缩

单列面板(最大宽度约 780):已选项目芯片 → 文件名与格式 → 预设三选一 → 高级项(字典、分卷、线程、密码)→ 开关项 → 底部预计体积与用时、取消与开始。

- 预设:极速 / 均衡(默认)/ 最小体积,选中态用强调色边框和浅底。
- 预计体积和用时随预设、线程数实时更新。
- 开关项每项带一行说明,说明讲清后果。

### 任务

任务列表:图标、名称、类型说明、暂停、取消、进度条、已处理量、速度、剩余时间。完成后用深色提示条显示结果和"打开文件夹"。

## 6. 组件规则

- **主按钮**:强调色填充,文字用 `accent-ink`。同一区域只放一个。
- **次按钮**:透明底,悬停显示 `hover`;需要边框时用 `line` 描边。
- **危险按钮**:文字用 `danger`,不做大面积红底。
- **输入框**:`line` 边框,聚焦时 2px `accent` 轮廓。
- **文件类型图标**:圆角小方块加扩展名缩写,文件夹用强调浅底,图片 / 文档 / 代码 / 二进制各用一个固定色相,不引入新的强调色。
- **选中行**:`accent-soft` 底;悬停行:`hover` 底。
- **进度条**:6px 高、全圆角,`accent` 填充。
- **开关**:36×22,开启为 `accent`。
- **加密标记**:用锁图标,不用文字。
- 图标:线性风格,1.7 描边,16px,圆头圆角。

## 7. 交互规则

- 所有主要操作都有键盘快捷键,并在界面可发现(如搜索框显示 `Ctrl F`,macOS 显示 `⌘ F`)。
- 键盘焦点必须可见。
- 拖拽:文件拖入窗口 = 添加;压缩包拖到文件夹 = 解压。
- 危险操作(删除、覆盖)需要确认;可撤销的不弹确认。
- 错误提示说清原因和解决办法,不道歉,不用含糊措辞。
- 文案:动词开头、具体,如"解压到…""开始压缩""打开文件夹"。
- 动效克制:只用于状态过渡(开关、进度),时长不超过 200ms;尊重系统"减少动态效果"设置。
- 无障碍:接入 AccessKit(或框架等价能力),所有控件有可读名称;文字对比度不低于 WCAG AA。

## 8. 平台差异

- 视觉稿未画各系统的原生窗口按钮。窗口标题栏的具体做法(自绘或系统原生)在 UI 框架定案后决定。
- 快捷键、菜单位置遵循各平台惯例(macOS 菜单栏、Windows / Linux 窗口内菜单)。
- 文案支持多语言,不得把中文写死在代码里;使用资源文件。
