# GPUI Kit 验证清单

目的:回答 `decisions.md` D3 里的三个问题,决定 UI 用 GPUI Kit 还是退回 Slint。
验证程序是一次性的,位于 `apps/gpui-probe`,验证完就删。

## 运行

```
cargo run --release -p gpui-probe
```

需要 Rust 1.96 以上。第一次构建要下载并编译约 800 个依赖,macOS 上约 1 分钟。
终端会打印检查清单;窗口里是同样的内容。

各系统的额外依赖:

| 系统 | 需要 |
|---|---|
| macOS | Xcode(含 Metal 工具链) |
| Windows | Visual Studio Build Tools(C++ 工作负载) |
| Linux | `libxkbcommon`、`libwayland`、`libxcb`、`vulkan` 相关开发包和 `pkg-config` |

Linux 缺依赖时报错信息会指出缺哪个库;请把原文贴回来。

## 要做的事

1. **输入法**。在第一个输入框用系统自带的拼音、五笔、日文输入法输入:
   - 候选框出现的位置是否紧贴光标?
   - 选字后文字是否正确上屏?
   - 组合输入过程中(下划线状态)按退格、方向键、回车是否正常?
   - 中英文切换、全角标点是否正常?
   - 在文字中间插入、选中后替换、复制粘贴是否正常?
2. **密码框**。重复上面的输入;确认字符被遮住,眼睛按钮能切换显示。
3. **百万行列表**。
   - 拖动滚动条、滚轮、按 PageDown / End,是否有卡顿或空白闪烁?
   - 点"开始持续重绘",边滚动边读帧率。
   - 在活动监视器 / 任务管理器 / `top` 里看内存占用,记下数字。
   - 中文名称列是否正常显示,没有方块或乱码?
4. **渲染**。窗口是否完整显示、有无花屏、缩放窗口是否跟手、深色和浅色系统主题下是否正常?

## 请回报

对每台机器给出:

- 系统和版本(例如 macOS 15.1、Windows 10 22H2、Ubuntu 24.04 Wayland / X11)
- 显卡和驱动(虚拟机请注明,以及有没有 3D 加速)
- 上面四项的结果,有问题的写出现象
- 内存占用和滚动时的帧率

## 判定

| 结果 | 决定 |
|---|---|
| 三个系统的输入法和渲染都正常,滚动流畅 | 定案 GPUI Kit,开始做 GUI |
| 输入法有问题但只在个别系统 | 评估是否能绕过或等上游修复,期间先做 macOS / Windows |
| 无 GPU 或虚拟机无法启动 | 退回 Slint(有软件渲染) |
| 列表明显卡顿 | 先查是否是 debug 构建;release 下仍卡则退回 Slint |

验证期间 GUI 代码必须和 `rz-app` 解耦,保证能换框架。
