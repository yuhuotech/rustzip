# 常用位置重设计

## 已确认设计

- 默认桌面、下载、文稿、图片、音乐、视频，读取系统实际配置，仅显示存在的系统目录。
- 成功打开压缩包后记录所在目录，重复使用置前，最多 20 项；旧版最近打开记录回填，旧收藏保留，同一实际路径合并。
- 系统目录在前，自动目录按最近使用顺序；单击选中、双击进入，无每行操作按钮，右键移除记录。移除不删除文件，下次使用可重新出现。
- 位置总览与文件夹浏览共用列表/小图标切换，放在右上角，设置持久化。列表延续压缩包内文件行视觉，图标模式响应宽度并虚拟化，双击继续浏览并保留模式。
- 系统差异只在平台层，GUI 经应用层获取目录；元数据读取、路径规范化、设置保存不阻塞 GUI。

## 实施计划

1. 平台目录解析、应用层位置合并、MRU 与隐藏记录、旧数据兼容和持久化。
2. 统一列表/网格、导航、右键菜单、排序、右上角切换、空态和缺失目录提示。
3. 有意义的行为/重启/去重/布局测试，明暗主题真实渲染检查，fmt / Clippy / 全量测试。
