# Reviewed fuzz seed corpora

The nightly fuzz workflow copies these reviewed inputs into per-target persistent corpora before each run. Generated mutations and crashes stay in ignored `fuzz/corpus/` and `fuzz/artifacts/` directories, then the workflow caches the corpus and uploads failure artifacts.

- `zip_recovery/`: minimal valid, truncated, and missing-central-directory ZIPs built for RustZIP's recovery target.
- `bzip2/seed.bz2`: a small valid stream generated from `docs/product.md` with `cargo run -p rz -- a fuzz/corpus/bzip2/seed.bz2 docs/product.md`; it exercises block and checksum parsing.
- `chm/chm_basic.chm`: RustZIP's bounded LZX fixture, generated by MIT-licensed `rustchm` 0.1.2 and described in `crates/rz-formats/tests/fixtures/README.md`.
- `rar/container.rar`: the 87-byte BSD-2-Clause Homebrew test fixture used by `crates/rz-engine/tests/rar.rs`.
